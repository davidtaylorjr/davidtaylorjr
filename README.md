# Hi, I'm David Taylor 👋
I'm a software engineer and founder of **Taylor Creative Development**.
I build software around a simple belief:
> **Software should be experienced, not merely used.**
I care about the entire product — the problem it solves, the architecture underneath it, the way it feels to use, and the quality of what ultimately ships.
My work spans native applications, developer tools, simulation, and AI. I'm particularly interested in **agentic software development** and in finding better ways for humans and coding agents to work together.
## What I'm Building

A native weather app focused on making weather information beautiful, understandable, and genuinely useful.
### 🤖 Taylor ACP
An open-source Agent Client Protocol implementation built for deeply integrated agentic development, with Xcode as its primary target.
### 🥗 Nutrition Camera
A camera-first nutrition app exploring how computer vision and AI can make food tracking dramatically easier.
